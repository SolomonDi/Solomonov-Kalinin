# Вейвлет-фильтрация сейсмограмм

Программа предназначена для вейвлет-фильтрации сейсмограмм. 
Для программы был разработан графический интерфейс, который позволяет 
выбирать семейство вейвлета, временное окно для фильтрации, а также 
степень разложения. Также в программе присутствует функция выбора 
и загрузки сейсмотрасс.

## Требования для запуска программы

- Python 3.12.4
- PyWavelets 1.7.0

## Установка библиотек

Перед запуском установите необходимые библиотеки через терминал:

pip install PyWavelets
pip install numpy
pip install matplotlib

## Использование программы

Для запуска программы необходимо перейти в папку с программой, 
открыть в данной папке терминал и ввести следующую команду: python Wavelet.py
