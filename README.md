# Вейвлет-фильтрация сейсмограмм

    Программа предназначенна для вейвлет-фильтрации сейсммограмм. Для программы был разработан графический интерфейс, который позволяет выбирать семейство вейвлета, временное окно для фильтрации 
    а также степень разложения. Также в программе присутствует функция выбора и загрузки сейсмотрасс.

# Требования для запуска программы
    python's version : 3.12.4;
    PyWavelets' version 1.9.0;

# Использование программы
    Для запуска программы необходимо перейти в папку с программой, открыть в данной папке терминал и ввести следующую команду: python Wavelet.py
